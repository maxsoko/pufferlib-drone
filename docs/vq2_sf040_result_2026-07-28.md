# VQ2-SF040 result — rejected

SF040 completed all 12 fixed training epochs but did not meet numerical
admission. Gate-2 validation weighted MSE improved from approximately `0.3140`
for the zero adapter to `0.2456755` at epoch 12, still over twelve times the
preregistered `0.02` ceiling. The frozen-base 256-value additive phase path is
therefore under-capacity and must not be screened.

Artifact finalization then failed because the local name `output` shadowed the
output path. The bug was after training and did not conceal an admissible
epoch. It is fixed in source, but SF040 is not retried unchanged and no SF040
checkpoint is promoted. The run sent zero FlightSim packets and made no sealed
test access.
