Gate 3 in 8/8 native control starts despite perfect transport. LC230 therefore
runs one paired offline intervention screen on the same seed and seed offset.

Sixteen independent `NumpyLC216Policy` objects must advance on public legal
observations. Rows 0--7 are unmodified Puffer controls. Rows 8--15 receive the
training-only native alignment-oracle plant action only while held public
progress equals raw index 2. The Puffer still advances recurrently on every
intervention tick. Paired groups must start byte-identically.

failing controls and oracle-rescued rows, with an oracle label for each query.

the oracle produces 8/8 Gate-3 passes and zero terminals, transport is exact,
all labels are finite and in envelope, and all records are phase 2.

The oracle and privileged native tail are training-only. They cannot enter a
Puffer admission screen, shadow, FlightSim control, or runtime observation.

exact NumPy batch-1 native screening. FlightSim remains frozen. VQ2 Submission remains forbidden.
